# DECISIONS

Short entries: chose X over Y because Z. Newest last.

1. **n8n 2.49.6, pinned** (`n8nio/n8n:2.49.6`) over a floating `latest` tag, because the same repo must behave the same everywhere; upgrades follow the runbook in the README.
2. **Postgres 16.6-alpine** for n8n's database over SQLite, as the spec requires, and the pinned tag matches the other repos' Postgres 16.
3. **Owner account from environment variables** (`N8N_INSTANCE_OWNER_MANAGED_BY_ENV` + bcrypt hash generated by `make setup`) over clicking through the setup screen, so a fresh clone and CI boot to a usable instance with no manual step.
4. **Workflows and credentials go in through the n8n CLI** (`import:workflow --activeState=fromJson`, `import:credentials`) inside the running container, rather than the public REST API. The CLI keeps fixed credential and workflow IDs, so cross-workflow references and credential links survive a fresh import, and it needs no API key to bootstrap. Plaintext credential JSON is piped over stdin into a `umask 077` temp file and deleted right after. The spec allows "REST API or documented steps"; this is the scripted equivalent.
5. **Fixed workflow IDs** (`lpMainIntake0001` …) so `Execute Workflow` nodes reference sub-workflows stably across instances.
6. **Task runners in internal mode for local/demo** (`N8N_RUNNERS_MODE=internal`) over a separate runner container, because it is one container fewer for reviewers; the Azure production profile uses external runners.
7. **`$env` access enabled in workflows** for non-secret settings (base URLs, model name, thresholds, flags) over hardcoding them, because tests must repoint base URLs at the mock server. API keys stay in n8n credentials, never in `$env` expressions.
8. **Test overlay file** (`docker-compose.test.yml` + `test` profile) over editing `.env` for tests, because Compose `environment:` overrides `env_file`, so the same `.env` serves both dev and e2e runs.
9. **Small `.env` reader** (`scripts/envfile.py`, ~40 lines) over adding `python-dotenv` (CONVENTIONS §1: plain code under 50 lines).
10. **Harness dependencies:** FastAPI + uvicorn (mock server, per spec), httpx (HTTP client for tests and admin scripts), bcrypt (owner password hash for the env-managed owner).
